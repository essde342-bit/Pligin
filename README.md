# Pligin

Плагин для диагностики и контролируемого тестирования Minecraft-сервера на **Paper 1.21.4**. Требуется **Java 21**.

## Возможности первой версии

- Сводка по серверу: ядро, версия, JVM, ОС, доступные CPU-потоки, занятая и максимальная память JVM, TPS и средний MSPT Paper.
- Игроки: список онлайна, мир и пинг каждого игрока.
- Миры: игроки, загруженные чанки, сущности и время мира.
- Бенчмарк: интервалы между тиками, среднее значение, P50, P95 и максимум.
- Нагрузочные тесты: временные ArmorStand-сущности, частицы, ограниченное выделение памяти и однопоточная CPU-нагрузка.
- TXT-отчёты с основными сведениями о сервере, игроках, мирах, плагинах, JVM и свободном месте на диске.
- Автоматическое завершение тестов, очистка временных сущностей, единый активный тест и пауза между запусками.

## Установка

1. Скачай `Pligin-1.0.0.jar` из GitHub Actions artifact после успешной сборки.
2. Положи JAR в папку `plugins` сервера Paper 1.21.4.
3. Перезапусти сервер.
4. Команды доступны операторам (`pligin.admin`, по умолчанию OP).

## Команды

| Команда | Что делает |
|---|---|
| `/ht help` | Список команд |
| `/ht status` | Сводка по серверу, TPS и MSPT |
| `/ht players` | Онлайн и пинг игроков |
| `/ht worlds` | Информация по мирам, чанкам и сущностям |
| `/ht ping [ник]` | Пинг игрока; без ника — свой пинг |
| `/ht benchmark [секунды]` | Бенчмарк интервалов серверных тиков (5–120 сек.) |
| `/ht report` | Сохранить TXT-отчёт в `plugins/Pligin/reports` |
| `/ht stress entities <число>` | Создать временные тестовые ArmorStand-сущности |
| `/ht stress particles <число>` | Вызывать импульс частиц раз в секунду |
| `/ht stress memory <МБ>` | Временно выделить указанное количество памяти |
| `/ht stress cpu <секунды>` | Загрузить один фоновый CPU-поток на 1–5 сек. |
| `/ht stop` | Остановить текущий тест и очистить его временные объекты |

Примеры: `/ht benchmark 30`, `/ht stress entities 100`, `/ht stress particles 300`, `/ht stress memory 16`, `/ht stress cpu 3`.

## Ограничения безопасности

Тестируй только сервер, который администрируешь или на тестирование которого у тебя есть разрешение. В `config.yml` есть лимиты для всех нагрузочных тестов. Плагин не запускает параллельные тесты; временные сущности удаляются автоматически по окончании теста или при выключении плагина. CPU-тест использует только один фоновый поток, а тест памяти по умолчанию ограничен 32 МБ.

Лимиты можно изменить в `plugins/Pligin/config.yml`, но повышать их на рабочем сервере без необходимости не стоит.

## Сборка

Проект собирается Gradle под Java 21. GitHub Actions автоматически собирает JAR при push в `main`; готовый файл появляется в разделе **Actions → Build Pligin → Artifacts**.
